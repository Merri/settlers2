It has been 29 years since the release of the original game, but only now we are about to see The Settlers II Gold
Edition getting released on the Commodore Amiga!

The release date has been set to October 18th 2025 and according to the description the game will not be a quick port
but instead a carefully crafted and optimized game for the Amiga.

For more details check out
the <Link href="https://lookbehindyou.de/en/product/thesettlers2amiga/">Look Behind You website</Link>!
